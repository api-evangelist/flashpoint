# Flashpoint

> Flashpoint is a threat intelligence company delivering decisive intelligence for cybersecurity, fraud prevention, corporate and physical security, vulnerability management, insider threat, and national security teams. Its Ignite platform and Flashpoint API surface data collected from illicit online communities, the deep and dark web, chat services, and open sources — exposing threat actors, compromised credentials, vulnerabilities, and fraud indicators.

Flashpoint exposes finished intelligence and raw data programmatically through a REST API at api.flashpoint.io, documented on the developer portal at docs.flashpoint.io. Security teams integrate alerting, data feeds, and finished intelligence into SOC, SIEM, and security automation workflows.

Notes for agents:
- The developer portal and API reference at docs.flashpoint.io require authentication (Auth0 / ReadMe login); public browsing is limited.
- The API base host is https://api.flashpoint.io. No public OpenAPI specification was found at the time of writing.
